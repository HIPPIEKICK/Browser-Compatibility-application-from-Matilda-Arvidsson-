BROWSER COMPATIBILITY

browser

/ˈbraʊzə/

noun

"Computer program (such as Internet Explorer or Mozilla Firefox) that enables internet users to access, navigate, and search World Wide Web sites."
-Business Dictionary

compatibility

/kəmˌpatɪˈbɪlɪti/

noun

"Ability of two or more systems or their components to work together without user intervention or modification."
-Business Dictionary

If HTML is a language, then we can view the web browsers as translator. All people doesn’t know all languages and the same goes for browsers. Different people use different browsers and different browsers read website code differently. Therefore it’s important to make sure that your website is compatible to a number of browers. Techopedia.com defines ”Browser compatibility” as “…the capability or flexibility of a website, web application, script or HTML design to function on different web browsers available in the market.
